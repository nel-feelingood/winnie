Установка и настройка

Готовых сборок нет: приложение собирается из исходников прямо на твоём Mac. Это занимает несколько минут и не требует Xcode. Выбери способ.

Если пользуешься Claude Code или другим ИИ-агентом с доступом к терминалу, скопируй промпт и вставь его агенту. Ключи и токены агенту не нужны — ты вставляешь их сам в настройках Winnie.

Промпт для ИИ-агента
Установи и настрой на этом Mac приложение Winnie — десктоп-питомца с чатом Claude (открытый код, MIT).
Репозиторий: https://github.com/nel-feelingood/winnie

ЧАСТЬ 1. УСТАНОВКА

1. Проверь, что это macOS 14 или новее и что стоят Command Line Tools (xcode-select -p). Если их нет, запусти xcode-select --install и попроси меня дождаться конца установки.
2. Клонируй репозиторий в ~/Developer/winnie. Если папка уже есть — сделай в ней git pull.
3. Запусти ./scripts/install.sh. Скрипт соберёт приложение, положит его в /Applications и запустит. Первая сборка идёт пару минут.
4. Убедись, что /Applications/Winnie.app существует и процесс Winnie запущен. Если сборка упала — покажи ошибку и предложи, как её исправить.

ЧАСТЬ 2. НАСТРОЙКА

Иди по шагам по порядку. Перед каждым шагом коротко объясни, что он даёт, и спроси меня: «Подключим сейчас или позже?» Если я отвечаю «позже» — переходи к следующему шагу и запомни, что отложено.

Правила для всей настройки:
- Никогда не проси меня присылать ключи, токены и секреты в чат и не вводи их сам. Я вставляю их только в окно настроек Winnie — оттуда они попадают в Связку ключей macOS.
- Твоя роль — вести меня: называй одно действие за раз («открой…», «нажми…») и жди, пока я отвечу «готово» или опишу, что вижу.
- Названия пунктов на сторонних сайтах могут немного отличаться — ориентируйся по смыслу.
- Системные настройки безопасности сам не меняй, только объясняй, что нажать.

5. Claude API — нужен, чтобы чат вообще работал.
   - На console.anthropic.com: пополнить баланс (Billing), затем API Keys → Create Key → скопировать ключ.
   - В Winnie: настройки (открываются сами при первом запуске, иначе — шестерёнка в окне чата) → раздел «API» → поле Claude → вставить ключ → «Сохранить». Если macOS спросит про доступ к Связке ключей — «Разрешать всегда».
   - Проверка: кликнуть по Винни и написать «привет» — он должен ответить.

6. Gmail — по желанию; Винни сможет читать почту и делать сводки. Доступ только на чтение, сервис Google бесплатный.
   - На console.cloud.google.com: создать проект → APIs & Services → Library → включить Gmail API.
   - OAuth consent screen: тип External, заполнить название и почту, в Test users добавить свой адрес.
   - Credentials → Create credentials → OAuth client ID → тип Desktop app → появятся Client ID и Client Secret.
   - В Winnie: «API» → «Почта · Gmail» → вставить Client ID и Client Secret → «Войти» → разрешить доступ в браузере. Предупреждение Google о непроверенном приложении — это нормально, приложение моё собственное.
   - Предупреди меня: пока проект в статусе Testing, входить придётся заново раз в 7 дней; кнопка Publish app на экране согласия это убирает.
   - Проверка: спросить Винни «что важного в почте?».

7. Telegram-бот — по желанию; тот же Винни в телефоне и напоминания в Telegram.
   - В Telegram написать @BotFather → /newbot → придумать имя и username → получить токен.
   - В Winnie: «API» → «Telegram» → вставить токен → «Подключить бота» → появится шестизначный код.
   - Отправить этот код своему боту в личном чате — бот привяжется ко мне и больше никому отвечать не будет.
   - Проверка: написать боту «привет». Напомни: бот работает, пока Winnie запущен на Mac.

8. Разрешения macOS. Объясни, что система спросит сама: уведомления — при запуске (нужны для напоминаний); микрофон и распознавание речи — при первом нажатии на микрофон; запись экрана — при первом скриншоте, после выдачи Winnie нужно перезапустить.

9. Итог. Коротко напиши: что установлено, что подключено, что отложено и как к этому вернуться (настройки Winnie → «API»; подробная инструкция: https://nel-feelingood.github.io/winnie/install.html). Упомяни, что MCP-серверы, свои API и сертификат «Winnie Dev» для пересборок описаны там же.

Что сделает агент

  1. Установит. Проверит macOS и Command Line Tools, скачает исходники, соберёт приложение, положит в /Applications и запустит.
  2. Поможет настроить. По шагам проведёт через ключ Claude API, Gmail и Telegram. Перед каждым шагом спросит: подключить сейчас или позже.
  3. Расскажет про разрешения macOS — уведомления, микрофон, запись экрана.
  4. Подведёт итог: что подключено, что отложено и как к этому вернуться.

1. Что понадобится

  • Mac с macOS 14 (Sonoma) или новее. Проверено на macOS 15 и Apple Silicon.
  • Command Line Tools — компилятор Swift и git. Полный Xcode не нужен.
  • Ключ Anthropic API с положительным балансом. Приложение бесплатное, но за запросы к Claude платишь ты — напрямую Anthropic, по их тарифам. Расходы видны в настройках.

2. Сборка и установка

Открой Терминал. Если Command Line Tools ещё не стоят, сначала установи их (появится системное окно, дождись окончания):

xcode-select --install

Затем скачай исходники и запусти установщик:

git clone https://github.com/nel-feelingood/winnie.git
cd winnie
./scripts/install.sh

Скрипт соберёт релизную версию, подпишет её, положит Winnie.app в /Applications, при первой установке разложит спрайты и запустит приложение. Первая сборка идёт пару минут — скачивается и компилируется единственная зависимость.

Винни появится в правом нижнем углу экрана, а его значок — в строке меню. В Dock приложения нет, так задумано.

3. Ключ Anthropic API

  1. Зайди в console.anthropic.com, пополни баланс и создай ключ в разделе API Keys.
  2. При первом запуске Winnie сам откроет настройки на разделе «API». Вставь ключ в поле Claude и нажми «Сохранить».

Ключ сохраняется в системной Связке ключей и больше нигде. Когда macOS спросит, можно ли Winnie читать его из Связки, нажми «Разрешать всегда».

Модель выбирается в разделе «Модель и расходы». Opus — самый умный и дорогой, Haiku — быстрый и дешёвый, его хватает для переводов и напоминаний.

4. Разрешения macOS

Система спросит о них сама — в тот момент, когда разрешение впервые понадобится.

РазрешениеЗачемКогда спросит
УведомленияНапоминания всплывают, даже если Винни спрятанПри запуске
Микрофон и распознавание речиДиктовка. Речь распознаётся на устройствеПри первом нажатии на микрофон
Запись экранаСкриншот области экрана из чатаПри первом скриншоте; после выдачи перезапусти Winnie

Изменить решение можно в Системных настройках → Конфиденциальность и безопасность.

5. Сертификат для подписи (по желанию)

Без сертификата приложение подписывается «на лету», и после каждой пересборки macOS считает его новым: заново спрашивает доступ к Связке ключей, микрофону и записи экрана. Если собираешься обновляться или менять код, один раз создай собственный сертификат:

  1. Открой «Связку ключей» → меню «Связка ключей» → «Ассистент сертификации» → «Создать сертификат…».
  2. Имя — Winnie Dev, тип удостоверения — «Самоподписанный корневой», тип сертификата — «Подпись кода».
  3. Нажми «Создать» и снова запусти ./scripts/install.sh — скрипт найдёт сертификат сам.

7. Gmail (по желанию)

Google не даёт сторонним приложениям общий доступ к почте, поэтому нужен собственный бесплатный OAuth-клиент. Winnie получает право только на чтение.

  1. В Google Cloud Console создай проект и включи в нём Gmail API.
  2. Настрой экран согласия OAuth: тип «External», в тестовые пользователи добавь свой адрес.
  3. Создай учётные данные → OAuth client ID → тип приложения Desktop app.
  4. В Winnie: настройки → «API» → «Почта · Gmail». Вставь Client ID и Client Secret, нажми «Войти» и разреши доступ в браузере.
Пока проект в статусе Testing, Google просит входить заново раз в 7 дней. Кнопка Publish app на экране согласия это убирает; для личного использования проверка Google не требуется, но при входе будет предупреждение о непроверенном приложении.

8. Telegram-бот (по желанию)

  1. Напиши @BotFather команду /newbot, придумай имя и получи токен.
  2. В Winnie: настройки → «API» → «Telegram». Вставь токен и нажми «Подключить бота» — приложение проверит его и покажет шестизначный код.
  3. Отправь этот код своему боту в личном чате. Теперь бот привязан к тебе и больше никому не отвечает.

Бот работает, пока Winnie запущен на Mac, и принимает только текст. После пяти неверных кодов код меняется.

9. MCP и свои API (по желанию)

  • MCP-серверы — раздел «MCP»: укажи адрес сервера. Если сервер использует OAuth, вход откроется в браузере; если токен — вставь его, он уйдёт в Связку ключей.
  • Свои HTTP-API — раздел «API»: базовый адрес, описание для медведя и токен. Запросы привязаны к указанному хосту и по умолчанию только читают; запись включается отдельным переключателем.

10. Обновление и удаление

Обновить

cd winnie
git pull
./scripts/install.sh

Чаты, заметки, настройки и свои спрайты сохраняются.

Удалить полностью

pkill -x Winnie
rm -rf /Applications/Winnie.app
rm -rf ~/Library/Application\ Support/Winnie   # чаты, заметки, события, память
defaults delete local.winnie.pet               # настройки
tccutil reset All local.winnie.pet             # выданные разрешения

Секреты удаляются в «Связке ключей»: найди записи сервиса local.winnie.pet и удали их.
