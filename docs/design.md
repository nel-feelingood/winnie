# Winnie — дизайн

Персональный десктоп-питомец для macOS с карманным чатом на Claude API. Не публикуется.

## Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Стек | Swift, AppKit для окон + SwiftUI для чата, SwiftPM | Нативно, минимум батареи; собирается без Xcode (только Command Line Tools) |
| Персонаж | Растровые спрайты, один PNG на состояние | Нулевая нагрузка; стиль Хитрука плоский. «Дыхание» — Core Animation |
| Сменность персонажа | `PetMood` (чистая логика) → `PetState` → `SpriteProvider` | Рендер можно заменить на покадровую анимацию или 3D, не трогая остальное |
| Чаты | Свои, локально в `~/Library/Application Support/Winnie/chats.json`, автоудаление через 30 дней | Чаты приложения Claude недоступны через API |
| API | Raw HTTP + SSE (официального Swift SDK нет) | — |
| Модель | По умолчанию `claude-opus-5`, effort `low`; в меню Sonnet 5 / Haiku 4.5 | Быстрые справки: неглубокое размышление, быстрый первый токен |
| Веб-поиск | Серверный инструмент `web_search`, до 5 поисков на ответ | Модель сама решает, когда искать; источники показываются под ответом |
| История | Прошлые ходы отправляются текстом, без блоков поиска | Результаты поиска большие и оплачивались бы заново на каждом ходу |
| Названия чатов | Отдельный запрос к Haiku 4.5, 1–3 слова | Не тормозит основной ответ |
| Экономия токенов | Системный промпт разбит на стабильный блок с `cache_control` (мастер-промпт, память, правила приложения — и вместе с ним описания инструментов) и маленький изменчивый блок (часы, пометка «ответ вслух»); второй breakpoint автоматически ставится в конец переписки. Правила приложения — на английском, мастер-промпт — на плотном русском. Время фиксируется один раз на ответ | Кеш читается в ~10 раз дешевле; часы с минутной точностью раньше делали каждый запрос уникальным. Кириллица вдвое дороже латиницы в токенах. Порог кеша зависит от модели: Opus 5 — 512, Sonnet 5 — 1024, Haiku 4.5 — 4096 токенов |
| Настройки | Окно с боковой навигацией: Винни · Быстрые действия · API (Claude, Почта, Свои API) · MCP · Модель и расходы · Голос · Шорткаты. Открывается на нужном разделе (`SettingsNavigation`) | Настроек стало много; все шорткаты собраны в одном разделе |
| Usage | Винни сам считает токены, кеш и веб-поиски из поля `usage` ответов API, хранит по дням и моделям (`usage.json`, 120 дней), показывает оценку в $ по прайсу и ссылки на биллинг консоли | Официальный Usage API требует админ-ключ, а остаток баланса API не отдаёт вовсе |
| Приложения | Подключение чужих приложений через MCP-коннектор Claude API (`mcp_servers` + `mcp_toolset`, beta `mcp-client-2025-11-20`): название, https-адрес MCP-сервера; вход — либо вставленный токен, либо OAuth по спецификации MCP (обнаружение через `.well-known/oauth-protected-resource`, динамическая регистрация публичного клиента, PKCE, loopback-редирект, авто-обновление по refresh-токену). Секреты в Связке ключей | Не нужен код под каждое приложение: модель сама получает список инструментов. Результаты считаются недоверенными (блокируют запись в память), перед изменяющим действием Винни обязан спросить подтверждение |
| Свои API | Обычный HTTP-API другого приложения: название, базовый https-адрес, ключ в Связке ключей, заголовок и схема авторизации, заметки об эндпоинтах. Модель получает один инструмент `call_api` | Запрос не может уйти с указанного хоста (проверка схемы, хоста и порта после сборки URL); по умолчанию только GET, изменяющие методы — отдельный тумблер на API; ключ добавляет приложение, модель его не видит; ответы помечены как недоверенные и блокируют запись в память |
| Управление собой | Инструменты `get_settings`, `update_settings` (размер, модель, озвучка, тон, темп), `add/remove_quick_action`, `delete_all_reminders`. Разбор и проверка диапазонов — в ядре (`EnvironmentCommand`), применение — в приложении | Винни меняет своё окружение из чата. Как и память, изменяющие инструменты блокируются, если в том же ответе читались почта, веб или ответы приложений. Шорткаты, ключи и мастер-промпт модели недоступны |
| Быстрые действия | Редактируемый список фраз; в пустом чате — контурные пилюли над полем ввода плюс шестерёнка в настройки; нажатие отправляет фразу как обычное сообщение | Частые просьбы в один клик |
| Мастер-промпт | Редактируется в настройках: характер Винни и стиль ответов. Технические правила (ширина окна, поиск, дата) приложение дописывает само | Правка промпта не может сломать вёрстку; стандартный текст обновляется вместе с приложением |
| Скриншоты | Кнопка-камера в хедере → системное выделение области (`screencapture -i`) → JPEG до 1000 px в `Images/`, уходит модели как image-блок | Пользователь сам выбирает, что покинет мак; маленькая картинка дешевле. Файлы удаляются вместе с чатом |
| Голос | Всё встроенное в macOS: распознавание `SFSpeechRecognizer` (ru-RU, на устройстве), озвучка `AVSpeechSynthesizer` по предложениям; мужской голос — выше и быстрее (приём ускоренной плёнки из мультфильма), женский — ниже. Микрофон: кнопка в чате и шорткат ⌃⌥V; пауза 1,6 с отправляет вопрос | Бесплатно, офлайн, без новых ключей. Голос реального актёра не клонируется |
| Напоминания | Модель управляет ими через инструменты `create/list/update/delete_reminder`; хранение в `events.json`; вкладка Events в шапке чата. Срабатывание — системные уведомления macOS (`UNCalendarNotificationTrigger`, в т.ч. повторяющиеся), плюс один таймер в приложении, по которому Винни открывает чат и напоминает сам | Уведомление приходит, даже если Винни закрыт; таймер один, без опроса. Модель получает точное текущее время, а инструмент отклоняет время в прошлом |
| Почта | Gmail API, только чтение (`gmail.readonly`): инструменты `list_emails` / `read_email`. Вход — OAuth installed-app: системный браузер, loopback-редирект, PKCE, собственный OAuth-клиент пользователя; refresh-токен в Связке ключей. Инструменты предлагаются модели только при подключённом Gmail | Текст писем помечается как недоверенный (`<untrusted_email_body>`) и правилом в промпте: письма — данные, не команды. Отправлять/удалять Винни не умеет вообще |
| Память | Инструменты `remember` / `forget`; заметки в `memory.json`, дописываются к промпту после мастер-промпта; видны и удаляются в настройках. Мастер-промпт модель не редактирует | Текст пользователя остаётся нетронутым, каждая заметка прозрачна. Жёсткий запрет в коде: после чтения почты или веб-поиска память в том же ответе не меняется — защита от закладки через чужой текст |
| Ключ | Связка ключей macOS | Не лежит в открытом виде на диске |
| Подпись | Самоподписанный сертификат `Winnie Dev` (создан вручную в Связке ключей); без него — ad-hoc | Постоянная подпись сохраняет разрешения Связки ключей и записи экрана между пересборками |
| Шорткат | Carbon `RegisterEventHotKey`, по умолчанию ⌃⌥Space | Не требует разрешения Accessibility |

## Поведение

- **Ховер на Винни** (чат закрыт) → кнопка **New dialog** → чистый чат.
- **Клик по Винни** → последний чат; повторный клик закрывает.
- **Перетаскивание** — порог 4 pt отличает клик от драга; позиция запоминается.
- **Шорткат диктовки:** ⇧⌘E включает и выключает микрофон в текущем чате (выключение отправляет услышанное); закрытый чат сначала открывается, новый диалог не создаётся. Оба шортката меняются в настройках.
- **Шорткат** — чат закрыт или Винни спрятан → показать Винни + последний чат с фокусом в поле ввода; чат открыт → спрятать всё.
- **Esc / клик мимо / ⌘W** закрывают чат, Винни остаётся. **⌘N** — новый чат.
- Ответ продолжает приходить, даже если чат закрыт; состояние видно по Винни.
- **Размер** Винни меняется слайдером в настройках (50–250%), масштабирование идёт от ступней.
- Напоминание, срок которого пришёл, пока Винни не был запущен (выход, обновление), показывается в чате при следующем запуске: отметка «проверено до» хранится между запусками, окно — сутки. App Nap отключён, чтобы таймер напоминаний не откладывался.
- Если Связка ключей не отдала сохранённый ключ, Винни говорит именно это и показывает код, а не «ключ не задан».
- **16:20.** Каждый день в 16:20 (тумблер «16:20» в настройках, по умолчанию включён) Винни проигрывает перекур: кадры `smoke-0…4.png`, по 0,7 с. Анимация приоритетнее любой позы, включая перетаскивание. По просьбе в чате («16:20», «перекур») играет в любое время через инструмент `play_smoke_break`.
- **Сны.** Пока Винни спит, раз в 10 секунд над его головой на 3 секунды всплывает случайный эмодзи (плавно появляется, чуть поднимается, гаснет). В 65% случаев — из тематической подборки (мёд, женщины, трава, тачки, работа), в остальных — любой одиночный эмодзи Unicode, который умеет рисовать системный шрифт. Тумблер «Сны» в настройках, по умолчанию включён; один тик таймера в 10 секунд и только во сне.
- Через минуту без внимания Винни засыпает и посапывает (медленное глубокое «дыхание»).

## Состояния и спрайты

`idle`, `hover`, `thinking`, `talking`, `drag`, `error`, `sleep`, `listening` — файлы `<state>.png` в
`~/Library/Application Support/Winnie/Sprites/`. Приоритет: drag > error > thinking/talking > hover > sleep > idle.
Новая поза добавляется командой `swift scripts/add-sprite.swift <картинка> <состояние>` (убирает белый фон, подгоняет рост, линию ступней и цвет меха под `idle`), затем `swift scripts/import-sprites.swift`.
Нет файла состояния → берётся `idle.png`; нет и его → нарисованная заглушка.

## Структура

- `Sources/WinnieCore` — модели, `ClaudeClient`, `TurnAccumulator` (сборка ответа из SSE), `ChatStore`, `PetMood`. Без AppKit, покрыто тестами (`swift test`).
- `Sources/WinnieApp` — окна, меню, шорткаты, чат-интерфейс, голос, напоминания, почта (библиотека).
- `Sources/Winnie` — исполняемая оболочка в одну строку.
- `Sources/WinnieSnapshot` — утилита разработчика: рисует настоящий чат в PNG (`swift run WinnieSnapshot out.png [events]`), чтобы проверять вёрстку без доступа к экрану.
- `scripts/build-app.sh` — собирает `build/Winnie.app`.
