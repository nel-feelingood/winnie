Винни-Пух на рабочем столе с чатом Claude внутри

Winnie — десктоп-питомец и ИИ-помощник в одном. Медведь из советского мультфильма живёт в углу экрана поверх всех окон, а по клику или шорткату открывает компактный чат: перевести, найти, напомнить, записать. Спросил, получил ответ, закрыл — без браузера и вкладок.

  • macOS 14+
  • Command Line Tools, Xcode не нужен
  • свой ключ Anthropic API
  • бесплатно · MIT

Установка — одним промптом. Скопируй и вставь в Claude Code или другого ИИ-агента с терминалом: он сам скачает, соберёт и запустит Winnie.

Промпт для установки
Установи на этот Mac приложение Winnie — десктоп-питомца с чатом Claude (открытый код, MIT).
Репозиторий: https://github.com/nel-feelingood/winnie

1. Проверь, что это macOS 14 или новее и что стоят Command Line Tools (xcode-select -p). Если их нет, запусти xcode-select --install и попроси меня дождаться конца установки.
2. Клонируй репозиторий в ~/Developer/winnie. Если папка уже есть — сделай в ней git pull.
3. Запусти ./scripts/install.sh. Скрипт соберёт приложение, положит его в /Applications и запустит. Первая сборка идёт пару минут.
4. Убедись, что /Applications/Winnie.app существует и процесс Winnie запущен. Если сборка упала — покажи ошибку и предложи, как её исправить.
5. Не проси у меня ключи API и не вводи их сам: ключ Anthropic я вставлю в настройках приложения, в разделе «API». Не меняй системные настройки безопасности.
6. В конце коротко напиши, что сделано и что осталось мне: вставить ключ, выдать разрешения (уведомления, микрофон, запись экрана) и, по желанию, создать сертификат «Winnie Dev». Подробности: https://nel-feelingood.github.io/winnie/install.html

Фичи

Полноценный помощник, до которого один клик или один шорткат.

💬

Карманный чат

Claude Opus, Sonnet или Haiku. Ответы печатаются на лету, с Markdown и веб-поиском. Чаты называются сами.

⏰

Напоминания

«Напомни завтра в десять позвонить». Разовые и повторяющиеся, с системным уведомлением.

📝

Заметки

Markdown-файлы с чистым редактором: меню по /, чекбоксы, картинки. Медведь ведёт их сам.

🎙️

Голос

Диктовка по шорткату и озвучка ответов средствами macOS. Бесплатно, распознавание на устройстве.

📸

Скриншоты

Выдели область экрана или вставь картинку из буфера — и спроси, что на ней.

⚡

Быстрые действия

Свои кнопки с готовыми инструкциями: перевод, сводка почты, таймер.

🧠

Память и характер

«Запомни, что…» — и он помнит между чатами. Характер задаётся редактируемым промптом.

🎛️

Управляет собой

«Стань побольше», «выключи сны», «добавь кнопку» — настройки меняются просьбой в чате.

💸

Расходы на виду

Учёт токенов и стоимости по моделям, экономный промпт с кэшированием.

Интеграции

Подключается к тому, чем ты уже пользуешься. Всё необязательно и настраивается в приложении.

🤖

Claude API

Прямое подключение к Anthropic со своим ключом: без посредников и подписок, платишь только за запросы.

📬

Gmail

Сводка почты и поиск писем. Доступ только на чтение — отправить или удалить письмо нельзя.

✈️

Telegram-бот

Тот же Винни в телефоне: та же память, события и напоминания, пока приложение запущено на Mac.

🔌

MCP-серверы

Подключай рабочие инструменты по Model Context Protocol, в том числе со входом через OAuth.

🌐

Свои HTTP-API

Адрес, описание и токен — и медведь ходит в твой сервис. Запросы привязаны к хосту, запись включается отдельно.

🍎

macOS

Системные уведомления, Связка ключей, распознавание и синтез речи, глобальные шорткаты, строка меню.

Приватность данных

Приложение говорит с Claude API напрямую. Наружу уходит только то, что ты сам отправил в чат.

🏠

Всё хранится локально

Чаты, события, заметки и память лежат в ~/Library/Application Support/Winnie — обычными файлами.

🔑

Секреты — в Связке ключей

Ключ API и токены никогда не попадают в файлы настроек и тем более в репозиторий.

🛡️

Защита от инъекций

Прочитав письмо, веб-страницу или данные MCP, медведь в этом ответе не может менять память, настройки и заметки.

👀

Почта только на чтение

Gmail подключается с правом gmail.readonly.

🔒

Telegram под замком

Бот отвечает только в привязанном личном чате; после пяти неверных кодов код меняется.

📖

Открытый код

Никаких серверов посередине и никакой аналитики. Всё, что делает приложение, можно прочитать.

Живой характер

Спрайты в духе мультфильма Фёдора Хитрука. Постоянной анимации нет — медведь не ест батарею.

Спит и видит сны

Минута без дела — и Винни засыпает. Над спящим медведем всплывают эмодзи: то, что ему снится. Чаще всего это мёд, женщины, трава, тачки и, увы, работа. Иногда — что угодно.

🍯 🐝 💃 💋 🌿 🍀 🏎️ 🚙 💻 📈 ☕️

Сны отключаются в настройках, в разделе «Поведение».

Перекур в 16:20

Каждый день ровно в 16:20 медведь устраивает перекур — даже если был спрятан. Можно попросить в чате: «перекур».
