Винни-Пух на рабочем столе с чатом Claude внутри

🏆 Ачивка разблокированаНакожено Серёжей · 20 сент. 2026

Winnie — десктоп-питомец и ИИ-помощник в одном. Медведь из советского мультфильма живёт поверх всех окон, а по клику или шорткату открывает компактный чат: спросил, получил ответ, закрыл — без браузера и вкладок.

  • Чат с Claude — веб-поиск, скриншоты, Markdown
  • Напоминания обычными словами, с уведомлениями
  • Заметки в Markdown, которые медведь ведёт сам
  • Голос — диктовка и озвучка, бесплатно
  • Почта — сводка Gmail, доступ только на чтение
  • Telegram-бот, MCP-серверы и свои API
GitHub

Вставь промпт в Claude Code или другого ИИ-агента с терминалом — он сам скачает, соберёт и запустит Winnie. Посмотреть промпт · установить руками

Бесплатно, MIT · macOS 14+ · нужен свой ключ Anthropic API · данные хранятся только на твоём Mac

Наведи на меня

Что он умеет

Это не просто картинка на экране, а полноценный помощник, до которого один клик или один шорткат.

💬

Карманный чат

Claude Opus, Sonnet или Haiku на выбор. Ответы печатаются на лету, с Markdown и веб-поиском. Чаты называются сами и хранятся 30 дней.

⏰

Напоминания

«Напомни завтра в десять позвонить» — и всё. Разовые и повторяющиеся, с системным уведомлением; Винни сам откроет чат и напомнит.

📝

Заметки

Обычные Markdown-файлы с чистым редактором без значков разметки: меню по /, чекбоксы, картинки, закрепление. Медведь умеет вести их сам.

🎙️

Голос

Диктовка по шорткату и озвучка ответов встроенными средствами macOS. Бесплатно, распознавание идёт на устройстве.

📸

Скриншоты и картинки

Выдели область экрана или вставь изображение из буфера — и спроси, что на нём. Кнопка прямо в поле ввода.

📬

Почта

Читает Gmail (только чтение) и делает аккуратную сводку: что важно, что можно пропустить.

✈️

Telegram-бот

Тот же Винни в телефоне, с той же памятью и напоминаниями, пока приложение запущено на Mac.

🔌

MCP и свои API

Подключай MCP-серверы (в том числе с OAuth) и любые HTTP-API — медведь научится работать с твоими сервисами.

⚡

Быстрые действия

Свои кнопки с готовыми инструкциями: «переведи», «сводка почты», таймер. Настраиваются в приложении или прямо из чата.

🧠

Память и характер

«Запомни, что…» — и он помнит между чатами. Мастер-промпт с характером Винни открыт для редактирования.

🎛️

Управляет собой

«Стань побольше», «выключи сны», «добавь кнопку» — настройки меняются обычной просьбой в чате.

💸

Расходы на виду

Учёт токенов и стоимости по моделям, экономный промпт с кэшированием и ссылка на пополнение баланса.

Для чего он на самом деле нужен

Мелкие дела, ради которых жалко открывать браузер. Спросил, получил ответ, закрыл — чат одноразовый.

🌍 Быстрый перевод

Переведи на английский, вежливо: «давайте перенесём созвон на четверг»

Выделил текст в ответе — всплывает кнопка Copy. Вставил в письмо и забыл про чат.

🔎 Найти и не утонуть во вкладках

Во сколько завтра закрывается мэрия и что взять с собой?

Ищет в вебе сам и отвечает коротко, со ссылками на источники. Ссылку можно скопировать по наведению.

⏰ Напоминание на бегу

Напомни через 40 минут достать пирог, и каждый будний день в 10 — стендап

Время понимает относительно текущего. В нужный момент придёт уведомление, а медведь откроет чат. Можно ответить «отложи на час».

📬 Утренняя сводка почты

Что важного в почте со вчера?

Дайджест с заголовками и списками: что требует ответа, что просто к сведению. Удобно повесить на кнопку быстрого действия.

📸 «Что это за ошибка?»

[скриншот области экрана] что не так и как починить?

Кнопка с камерой прячет чат, даёт выделить область и возвращает снимок уже во вложении. Картинку из буфера можно просто вставить.

📝 Заметки голосом и текстом

Запиши в заметку «Идеи»: добавить прогулку по экрану

Медведь создаёт и дополняет заметки сам. В сообщении на них можно сослаться через @ — «подумай над @Идеи».

🎙️ Руки заняты

⇧⌘E → «сколько граммов в стакане муки?»

Один шорткат включает диктовку из любого приложения, второй раз — выключает. Ответ Винни может прочитать вслух.

✈️ С телефона, пока Mac дома

Telegram: напомни вечером оплатить интернет

Бот — тот же Винни с той же памятью и событиями. Напоминания дублируются в Telegram.

Три вкладки — и ничего лишнего

Компактное окно рядом с медведем. Меняет размер, запоминает его и не отбирает фокус, когда приходит напоминание.

Живой характер

Спрайты в духе мультфильма Фёдора Хитрука. Никакой постоянной анимации — медведь не ест батарею.

Установка

Готовых сборок нет — приложение собирается из исходников прямо на твоём Mac. Xcode не нужен. Есть два пути.

1Попросить ИИ-агента

Скопируй промпт и вставь его в Claude Code или другого агента с доступом к терминалу — он всё сделает сам.

Промпт для ИИ-агента
Установи на этот Mac приложение Winnie — десктоп-питомца с чатом Claude (открытый код, MIT).
Репозиторий: https://github.com/nel-feelingood/winnie

1. Проверь, что это macOS 14 или новее и что стоят Command Line Tools (xcode-select -p). Если их нет, запусти xcode-select --install и попроси меня дождаться конца установки.
2. Клонируй репозиторий в ~/Developer/winnie. Если папка уже есть — сделай в ней git pull.
3. Запусти ./scripts/install.sh. Скрипт соберёт приложение, положит его в /Applications и запустит. Первая сборка идёт пару минут.
4. Убедись, что /Applications/Winnie.app существует и процесс Winnie запущен. Если сборка упала — покажи ошибку и предложи, как её исправить.
5. Не проси у меня ключи API и не вводи их сам: ключ Anthropic я вставлю в настройках приложения, в разделе «API». Не меняй системные настройки безопасности.
6. В конце коротко напиши, что сделано и что осталось мне: вставить ключ, выдать разрешения (уведомления, микрофон, запись экрана) и, по желанию, создать сертификат «Winnie Dev». Подробности: https://nel-feelingood.github.io/winnie/install.html

2Или руками — три команды

# один раз, если ещё не стоят
xcode-select --install

git clone https://github.com/nel-feelingood/winnie.git
cd winnie
./scripts/install.sh
  1. Скрипт соберёт релиз, подпишет его, положит Winnie.app в /Applications и запустит.
  2. При первом запуске откроются настройки — вставь ключ Anthropic API в разделе «API».
  3. Разреши уведомления, а при первом использовании — микрофон и запись экрана.
  4. ⌃⌥Space — показать или спрятать Винни, ⇧⌘E — диктовка. Оба шортката меняются.

Подробная инструкция — сертификат для подписи, разрешения, подключение Gmail, Telegram и MCP, обновление и удаление.

Твои данные остаются твоими

Никаких серверов посередине: приложение говорит с Claude API напрямую.

  • Всё хранится локально. Чаты, события, заметки и память лежат в ~/Library/Application Support/Winnie.
  • Секреты — в Связке ключей. Ключ API и токены никогда не попадают в файлы настроек.
  • Защита от инъекций. После чтения письма, веб-страницы или данных MCP медведь в этом ответе не может менять память, настройки и заметки.
  • Почта только на чтение. Gmail подключается с правом gmail.readonly — отправить или удалить письмо нельзя.
  • Telegram под замком. Бот отвечает только в привязанном личном чате; после пяти неверных кодов код меняется.
  • Открытый код. Всё, что делает приложение, можно прочитать — и поменять под себя.
